# 📊 Retail Sales Analysis Project

## 🎯 Objective
Analyze sales data to understand product performance, regional trends, and business insights.

---

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Data Visualization

---

## 📊 Key Features
- KPI analysis (Revenue, Orders, Profit)
- Product performance analysis
- Regional sales breakdown
- Monthly trend analysis

---

## 📈 Key Insights
- Laptop is the top revenue-generating product
- Electronics category dominates sales
- North region shows strong performance
- Sales trend is steady over time
